# 반도체 데이터 엔지니어링 — 반도체 설계·공정 AX 마스터 클래스

**파이썬을 활용한 반도체 데이터 분석과 업무 자동화**

이 저장소는 도서 『반도체 데이터 엔지니어링(가제)』(한빛아카데미)의 공식 실습 코드와 통합 데이터셋을 제공합니다. 교재의 목차와 폴더 구조가 1:1로 대응하므로, 학습 중인 절의 코드를 바로 찾아 실행할 수 있습니다.

---

## AlphaChip_V2 프로젝트 세계관

이 책의 모든 코드는 하나의 시나리오로 이어집니다.

> 완전 자율주행 차량용 NPU **AlphaChip_V2**(3나노 EUV 공정)를 양산하던 중 원인 미상의 수율 급락이 발생했습니다. 설계는 바뀌지 않았고 레시피도 그대로인데, 로트가 진행될수록 불량률이 계단식으로 올라갑니다. 설계팀은 타이밍 슬랙이 무너진 경로를 확인했지만 그 칩이 언제 어디서 만들어졌는지 모르고, 공정팀은 챔버 온도가 흔들린 이력을 갖고 있지만 그때 만든 칩이 실제로 불량이 되었는지 알지 못합니다. 두 데이터가 서로 다른 시스템에 갇혀 있기 때문입니다.

독자는 이 프로젝트에 투입된 **인텐트 아키텍트(Intent Architect)**로서, 5,000행 통합 데이터셋을 파싱하고 분석해 원인을 규명하고, 머신러닝으로 고장을 예측하며, 최종적으로 트러블슈팅 AI 코파일럿을 배포합니다.

> **스포일러 안내**
> 수율 급락의 원인은 6장에서 독자가 직접 데이터로 규명하도록 설계되어 있습니다. 이 저장소의 문서와 코드 주석은 6장 이전 단계에서 원인을 미리 밝히지 않습니다. `data/data_generator.py`에는 인과관계가 수식으로 들어 있으므로, 스스로 찾아보고 싶다면 6장을 마친 뒤 열어 보기를 권합니다.

## 실습 환경 구축

의존성 충돌을 방지하기 위해 반드시 **파이썬 가상환경(venv)** 위에서 실행합니다.

### 요구 사양

| 항목 | 사양 |
|---|---|
| OS | Windows 10 이상 / Ubuntu 22.04 LTS 이상 (WSL2 권장) |
| Python | **3.14** (최소 3.12 이상) |
| IDE | Visual Studio Code (Python Extension, Remote-SSH) |
| Database | SQLite3 (Python 표준 라이브러리 내장) |

> numpy 2.5 이상이 Python 3.12 이상을 요구하므로, 3.10·3.11 환경에서는 `requirements.txt`의 조합을 그대로 설치할 수 없습니다.

### 설치 절차

```bash
# 1) 저장소 클론
git clone https://github.com/aagicap/Semiconductor-AX-Masterclass.git
cd Semiconductor-AX-Masterclass

# 2) 가상환경 생성 및 활성화
python -m venv .venv
.venv\Scripts\activate         # Windows
source .venv/bin/activate      # Linux / macOS

# 3) 의존성 설치
pip install -r requirements.txt

# 4) 설치 확인
python check_environment.py

# 5) 통합 데이터셋 생성
python data/data_generator.py
```

`check_environment.py`가 가상환경 격리와 패키지 설치 상태를 모두 `OK`로 출력하면 준비가 끝난 것입니다.

> **가상환경 폴더명은 반드시 `.venv`로 만듭니다.** `.vscode/settings.json`이 인터프리터 경로를 `.venv` 기준으로 고정해 두었기 때문에, `venv`나 `env` 같은 다른 이름을 쓰면 VS Code가 시스템 파이썬을 선택합니다. 이미 다른 이름으로 만들었다면 폴더를 지우고 다시 만드세요. 가상환경은 내부에 경로를 절대 경로로 기록하므로 이름만 바꾸거나 폴더를 옮기면 정상 동작하지 않습니다.

### 편집기 설정 (1.2절)

저장소 루트의 `.vscode/settings.json`은 이 프로젝트를 여는 모든 사람에게 같은 규칙을 적용합니다. 인터프리터 경로, 저장 시 자동 서식, 줄바꿈 문자와 인코딩이 고정되어 있어 운영체제가 달라도 결과가 갈리지 않습니다.

인터프리터 경로는 **윈도우 기준**으로 적어 두었습니다.

```jsonc
"python.defaultInterpreterPath": "${workspaceFolder}/.venv/Scripts/python.exe"
```

macOS와 리눅스에서 실습한다면 이 줄만 아래와 같이 바꿉니다.

```jsonc
"python.defaultInterpreterPath": "${workspaceFolder}/.venv/bin/python"
```

설정이 적용되지 않는다면 `Ctrl+Shift+P` → `Developer: Reload Window`로 창을 새로 고치거나, `Python: Select Interpreter`에서 `.venv` 항목을 직접 선택하세요.

다음 확장을 함께 설치해야 설정이 온전히 동작합니다. 설치 전에는 `settings.json`의 서식 도구 지정 줄에 경고 표시가 나타나는데, 오타가 아니라 해당 확장을 찾을 수 없다는 뜻입니다.

| 확장 | 용도 |
|---|---|
| Python | 인터프리터 연동, 디버깅, 언어 서버 |
| Pylint | 코드 품질 검사 |
| Black Formatter | 저장 시 코드 서식 자동 통일 |
| Remote - SSH | 원격 서버 접속 개발(선택) |

### 원격 개발 환경 (1.2절)

망분리된 분석 서버에서 실습하는 경우 VS Code Remote-SSH로 접속한 뒤, 저장소 루트에서 다음을 실행해 현재 실행 위치를 확인합니다.

```bash
python part1_python_automation/ch01/ch01_02_remote_check.py
```

세션 유형, 인터프리터 경로, 작업 디렉터리, 데이터 접근 가능 여부가 한 화면에 출력됩니다. 분석 결과가 재현되지 않을 때 가장 먼저 확인할 정보입니다.

### API 키 설정 (1.5절 / 12~13장 실습)

저장소 루트에 `.env` 파일을 만들고 키를 넣습니다. 이 파일은 `.gitignore`에 등록되어 있으므로 절대 커밋되지 않습니다.

```
OPENAI_API_KEY=sk-...
```

키 발급과 결제 등록 절차는 **온라인 부록 B**에서 안내합니다. 1.5절 실습은 키가 없어도 진행할 수 있으므로, 결제 수단 등록은 12장에서 실제로 API를 호출할 때 해도 됩니다.

## 통합 데이터셋

`data/data_generator.py`를 실행하면 물리적 인과관계가 주입된 5,000행 CSV가 생성됩니다. 난수 시드가 고정되어 있어 **누가 실행해도 동일한 데이터**가 만들어집니다.

### 구조

```
5,000행 = 10 로트 × 5 웨이퍼 × 100 다이
장비는 웨이퍼 단위로 배정됩니다(한 웨이퍼는 한 식각 챔버에서 처리).
```

### 컬럼

| 구분 | 컬럼 |
|---|---|
| 메타데이터 | Timestamp, Lot_ID, Wafer_ID, Die_X, Die_Y, Equipment_ID |
| FDC (공정) | Voltage, Chamber_Temp, Pressure, Gas_Flow |
| EDA (설계) | Path_ID, Operating_Freq, Worst_Slack, Leakage_Power |
| 결과 지표 | Pass_Fail, Error_Code |

`Leakage_Power`에는 센서 통신 유실을 가정한 결측치 2.5%가 포함되어 있습니다. 4장 결측치 제어 실습에 사용합니다.

### 에러 코드

| 코드 | 조건 | 의미 |
|---|---|---|
| `NORMAL` | 정상 | 특이사항 없음 |
| `ERR-T101` | Worst_Slack < 0 | 타이밍 에러 (불량) |
| `ERR-G202` | Gas_Flow < 88 sccm | 가스 유량 저하 경고 (양품이나 장비 상태 이상 신호) |

### 증상 지표

| 항목 | 값 |
|---|---|
| 전체 불량률 | 16.08% |
| 로트별 불량률 추이 | LOT_00 0.2% → LOT_09 62.2% |
| 수집 구간 | 2026-01-01 08:00 ~ 2026-01-18 16:35 |

로트가 진행될수록 불량률이 상승합니다. 여기까지는 증상일 뿐이며, 무엇이 나빠지고 있는지를 밝히는 것이 6장과 11장의 과제입니다.

### 가상 데이터 고지

이 데이터셋은 학습을 위해 생성한 가상 데이터입니다. 실존 기업의 공정 조건, 레시피, 수율 수치와 무관합니다. 다만 온도가 오르면 누설 전력이 늘고 타이밍 마진이 줄어드는 물리적 인과관계를 수식으로 주입했으므로, 분석 기법을 익히는 목적에서는 실제 데이터와 동일하게 동작합니다.
